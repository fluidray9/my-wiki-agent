# DeepSeek

**DeepSeek（深度求索）** 是一家中国人工智能公司，专注于开发大语言模型和推理能力提升。

## 核心产品

- **DeepSeek-R1**：专注于推理能力的大语言模型，以强化学习为核心训练方法
- **Distill 系列**：基于 R1 知识蒸馏的轻量版本，适合本地部署
