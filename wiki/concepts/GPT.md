# GPT

GPT (Generative Pre-trained Transformer) is a Transformer-based model introduced by OpenAI. The original GPT was followed by GPT-2, GPT-3, and beyond.

## Key Features
- Autoregressive: generates text token by token
- Left-to-right architecture
- Pre-training on large text corpus
