# Large Language Model

A Large Language Model (LLM) is a neural network trained on large amounts of text data. LLMs can understand and generate human language.

## Key Properties
- Scale: billions of parameters
- Pre-training: learns language patterns from vast text corpora
- Few-shot learning: can adapt to new tasks with minimal examples

## Notable Examples
- [[GPT]] models (OpenAI)
- [[BERT]] (Google)
- Claude (Anthropic)
- Llama (Meta)

- [[TransformerArchitecture]] — most LLMs are based on Transformers
