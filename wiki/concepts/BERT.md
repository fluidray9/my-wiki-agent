# BERT

BERT (Bidirectional Encoder Representations from Transformers) is a Transformer-based model introduced by Google in 2018. It achieved state-of-the-art results on NLP benchmarks.

## Key Features
- Bidirectional: processes text in both directions
- Pre-training: learns from large corpus, then fine-tunes
- Masked language modeling
